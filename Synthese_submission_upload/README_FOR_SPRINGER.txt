Main manuscript: EinsteinTDE.tex

Local compilation command:
pdflatex EinsteinTDE.tex
biber EinsteinTDE
pdflatex EinsteinTDE.tex
pdflatex EinsteinTDE.tex

The package includes the local style files, bibliography files, and image files
needed to compile EinsteinTDE.tex with pdfLaTeX and Biber.

The response letter is EinsteinTDEreply.tex and compiles with the same local files.
The marked-up manuscript is supplied as diff.pdf.
